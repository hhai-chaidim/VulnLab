# Glossary — Thuật ngữ Cybersecurity

| Thuật ngữ | Giải thích |
|-----------|-----------|
| CVE | Common Vulnerabilities and Exposures — mã định danh lỗ hổng công khai |
| CVSS | Common Vulnerability Scoring System — hệ thống chấm điểm mức nghiêm trọng |
| NVD | National Vulnerability Database — cơ sở dữ liệu lỗ hổng quốc gia (Mỹ) |
| PoC | Proof of Concept — mã chứng minh lỗ hổng có thể khai thác |
| RCE | Remote Code Execution — thực thi mã từ xa |
| LPE | Local Privilege Escalation — leo thang đặc quyền cục bộ |
| SQLi | SQL Injection — chèn câu lệnh SQL |
| XSS | Cross-Site Scripting — chèn mã script qua trình duyệt |
| SUID | Set User ID — bit quyền đặc biệt trên Linux |
| Sanitize | Làm sạch đầu vào để ngăn chặn injection |

> Bảng sẽ được bổ sung thêm trong quá trình research.
